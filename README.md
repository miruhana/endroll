# エンドロール

公務員の会議業務を「準備・記録・整理・共有」まで支える議事録作成アプリです。
会議資料（PDF・Word・Excel）と文字起こしを取り込み、論点ごとの議事録と、決定事項・未決事項・宿題の「案」を作ります。

## 使い方

公開URLを開くだけで使えます（インストール・ログイン不要）。

1. 新しい会議を作り、会議情報を入力する
2. 資料（PDF・Word・Excel）と文字起こしテキストを取り込む
3. 「議事録を作る」で論点別の議事録と、決定・未決・宿題の案を作る
4. 内容を確認・修正して、Word または Markdown で保存する

## 安全性について

- **データはお使いのブラウザの中だけに保存されます。** 開発者のサーバーや他の利用者には送られません。別の端末・別のブラウザからは見えません
- 共有PCでは、利用後にブラウザのサイトデータを削除してください
- **AI機能（議事録の作成・会議への質問）は任意です。** 使うには、画面右下の「AIの設定」からご自身の Anthropic APIキーを入力します。キーはこの端末のブラウザにだけ保存されます
- AIを使うと、会議の文字起こしと資料の内容が Anthropic 社のサーバー（国外）へ送信されます。機密区分が「庁内限り」「要配慮（個人情報等）」の会議は、所属組織のルールを確認してから使ってください
- AIが作った内容は必ず「案」です。最終的な確認と責任は、作成・承認する職員にあります
- 通信先は Anthropic API と、資料の読み取りに使うライブラリ（cdnjs）・Webフォントのみに制限しています（Content-Security-Policy）
